**Program:** Combined BCA 3rd Semester  
**Institution:** Department of Computer Science & Applications, Mandsaur University  
**Academic Budget:** 46 Sessions (30 Continuous Theory Lectures + 16 Practical Lab Sessions = 92 Hours Total)

---

## 📌 Course Overview

This repository contains the complete curriculum, self-study theory lecture guides, practical lab manuals, and architectural blueprints for **Web Technology & Cloud Computing Applications – I**. 

The course provides a seamless progression from fundamental internet protocols, static HTML5 authoring, and dynamic CSS styling, through client-side JavaScript programming, to server-side PHP development and MySQL database integration.

## 🛠️ Pedagogical Approach & Scaffolding

This course employs the **Progressive Scaffolding & Fading Model** to guide novice BCA students from guided learning to complete independence:
1. **Labs 01–05 (Scratch Coding):** Students code every HTML/CSS tag line-by-line from scratch to build muscle memory.
2. **Labs 06–11 (Scaffolded Starters):** Code templates provide structural boilerplate with `TODO:` comments guiding logic implementation.
3. **Labs 12–16 (Skeleton Projects):** Multi-file project skeletons require students to integrate frontend forms with backend PHP/MySQL databases.
