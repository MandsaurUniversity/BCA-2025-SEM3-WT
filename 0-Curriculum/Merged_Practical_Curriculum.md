# Combined Practical Curriculum: Web Technology & Cloud Computing Applications – I Lab

## Course Overview

* **Course Code:** 25SACS070P / 25BCC100P (Combined Stream Practical Syllabus)
* **Course Title:** Web Technology Lab & Cloud Computing Applications – I Lab
* **Target Program & Semester:** BCA (System Administration & Cyber Security) & BCA (Cloud Computing) — Semester-III
* **Academic Year / Assessment Year:** 2026-2027
* **Teaching Scheme:** L-0 T-0 P-4 C-2
* **Total Duration:** 32 Practical Hours (16 Continuous 2-Hour Hands-on Lab Sessions)
* **Combined Course Duration (Theory + Practical):** 46 Sessions (92 Total Hours)

---

## Course Objectives

* To gain comprehensive, hands-on experience in building static, styled, dynamic, and database-driven web applications using HTML, HTML5, CSS, Bootstrap, JavaScript, and PHP.
* To apply practical web development techniques for designing responsive user interfaces, dynamic client-side DOM manipulation, and server-side data processing.
* To master client-side validation, event handling, media integration, interactive components, and backend database interaction.

---

## Course Outcomes (COs)

Upon successful completion of this practical lab course, students will be able to:

1. **CO1:** Design and structure web content using fundamental HTML elements, text formatting, lists, tables, frames, and embedded audio/video multimedia.
2. **CO2:** Implement inline and external CSS styling, class/ID selectors, box-model properties, centered container layouts, and responsive UI components using Bootstrap.
3. **CO3:** Program client-side interactive features using JavaScript, including dialog prompt greetings, delayed background transformations, DOM styling, and visibility toggling.
4. **CO4:** Construct robust HTML forms and enforce client-side validation constraints using JavaScript.
5. **CO5:** Develop backend PHP applications to process form data (GET/POST) and integrate PHP scripts with relational databases (MySQL) for secure user authentication and dynamic data persistence.

## Detailed List of Consolidated Experiments

### **Experiment 1: Basic HTML Structure, Text Formatting, Lists & Departmental Page Creation**
* **Objective:** Understand basic HTML tags, document structure, headings, paragraphs, and list elements.
* **Tasks:**
  1. Create a basic webpage describing your department using heading tags (`<h1>` to `<h6>`), paragraph tags (`<p>`), and text formatting.
  2. Include a list (`<ul>` or `<ol>`) detailing department courses or ingredients of a favorite dish (e.g., three main ingredients).
* **Coverage Note:** `[Covers: 25SACS070P Exp 1, 12 | 25BCC100P Exp 1]`

---

### **Experiment 2: Hyperlinks, Image Navigation, Back-to-Top Scrolling & Multimedia Embedding**
* **Objective:** Implement internal/external navigation, image links, page scrolling anchors, and media integration.
* **Tasks:**
  1. Create hyperlinks (`<a>`) on specific words like "Wi-Fi" and "LAN" directing to external Wikipedia reference pages.
  2. Insert an image (`<img>`) and make it clickable so that clicking the image navigates the user to another web page.
  3. Customize the background color of the web page and add an anchor link at the bottom that smoothly scrolls the user back to the top of the page.
  4. Embed Audio (`<audio>`) and Video (`<video>`) media controls directly into the web page.
* **Coverage Note:** `[Covers: 25SACS070P Exp 2, 3, 4, 9 | 25BCC100P Exp 2, 3, 4, 9]`

---

### **Experiment 3: HTML Tables for Time-Table & Infrastructure Layouts, Frame Division**
* **Objective:** Utilize HTML tables for structured data display, web layout design, and frame-based multi-panel navigation.
* **Tasks:**
  1. Create a structured HTML table (`<table>`, `<tr>`, `<td>`, `<th>`) to display your weekly class time-table.
  2. Use HTML tables to create a visual multi-column layout describing your university's campus infrastructure.
  3. Divide a web page into 3 distinct frames (`<frameset>`/`<iframe>`): 20% on the left for page navigation links, 60% in the center for main content body, and 20% on the right for remarks.
* **Coverage Note:** `[Covers: 25SACS070P Exp 5, 6, 8 | 25BCC100P Exp 5, 6, 8]`

---

### **Experiment 4: Semantic Page Layout using `<div>` and `<span>` Structural Elements**
* **Objective:** Replace legacy table layouts with modern semantic block (`<div>`) and inline (`<span>`) container tags.
* **Tasks:**
  1. Re-design the university infrastructure page from Experiment 3 using `<div>` and `<span>` tags instead of `<table>` tags to structure header, content sections, sidebars, and footer.
* **Coverage Note:** `[Covers: 25SACS070P Exp 7 | 25BCC100P Exp 7]`

---

### **Experiment 5: Inline CSS Styling & Centralized External CSS Rules with Classes & Centered Containers**
* **Objective:** Apply inline, internal, and external Cascading Style Sheets (CSS) to format web page aesthetics.
* **Tasks:**
  1. Apply inline CSS (`style=""`) to modify text colors, apply bold/underline/italic styles, and set unique paragraph background colors.
  2. Extract styles into an external CSS file (`style.css`), link it using `<link>`, group paragraphs under a shared CSS class (`.highlight`), and verify instant style updates across pages.
  3. Write a CSS rule targeting a `<div>` element to set its background color to light gray (`#f2f2f2`), center its content horizontally and vertically, and fix its width to 80% of its parent container.
* **Coverage Note:** `[Covers: 25SACS070P Exp 10, 11, 13 | 25BCC100P Exp 10, 11]`

---

### **Experiment 6: HTML Form Design & Form Control Elements**
* **Objective:** Construct interactive web forms using various HTML input controls.
* **Tasks:**
  1. Design a simple user form to capture profile details: Name, Age, Address, Favorite Subject, Favorite Movie, and Favorite Singer.
  2. Add diverse form controls including text fields, radio buttons (gender selection), checkboxes (hobbies/interests), password fields, textareas, reset buttons, and a submit button (`<input type="submit">`).
* **Coverage Note:** `[Covers: 25SACS070P Exp 15, 16 | 25BCC100P Exp 12, 13]`

---

### **Experiment 7: Responsive Web Design using Bootstrap Framework**
* **Objective:** Build modern responsive web layouts and components using the Bootstrap CSS framework.
* **Tasks:**
  1. Design a responsive online shopping / e-commerce web page using the Bootstrap grid layout system (`container`, `row`, `col-*`).
  2. Build a responsive navigation bar (`navbar`) with branding, nav links, and dropdown menus.
  3. Implement an automated interactive image slider (`carousel`) showcasing promotional banners.
* **Coverage Note:** `[Covers: 25SACS070P Exp 17, 18, 19 | 25BCC100P Exp 14, 15, 16]`

---

### **Experiment 8: JavaScript Basics, User Interaction (`prompt`, `alert`), Greetings & Timed Page Actions**
* **Objective:** Implement foundational client-side JavaScript logic, dialog boxes, and timed window events.
* **Tasks:**
  1. Write a script that prompts the user for their name via `prompt()` upon page load, then displays a personalized greeting message (`"Hello, [Name]!"`) inside an `<h2>` heading on the page.
  2. Display an automatic pop-up alert (`alert()`) containing welcome information as soon as the page finishes loading.
  3. Program a JavaScript function using `setTimeout()` to automatically change the webpage's background color 5 seconds after page load.
* **Coverage Note:** `[Covers: 25SACS070P Exp 14, 21, 22 | 25BCC100P Exp 18, 19]`

---

### **Experiment 9: Client-Side Form Validation using JavaScript**
* **Objective:** Validate user input on HTML forms prior to server submission using JavaScript routines.
* **Tasks:**
  1. Create an HTML form and attach JavaScript submit validation functions to check input constraints (e.g., verify that the user's entered Age is numeric and lies strictly between 1 and 150; check non-empty required fields).
* **Coverage Note:** `[Covers: 25SACS070P Exp 20 | 25BCC100P Exp 17]`

---

### **Experiment 10: Dynamic DOM Manipulation (Interactive Styling & Toggling Elements)**
* **Objective:** Manipulate Document Object Model (DOM) elements dynamically based on real-time user events.
* **Tasks:**
  1. Write a JavaScript program with event triggers (buttons/clicks) that dynamically bolds, italicizes, or underlines specific words and phrases on the page.
  2. Create a hidden `<div>` element on the web page (`display: none`) and program a JavaScript function to display/toggle it when the user clicks a button.
* **Coverage Note:** `[Covers: 25SACS070P Exp 23, 24 | 25BCC100P Exp 20, 21]`

---

### **Experiment 11: Comprehensive Departmental Website & Interactive E-Book Interface Development**
* **Objective:** Synthesize HTML, CSS, and JavaScript skills into complete web application projects.
* **Tasks:**
  1. Construct a multi-page departmental website integrating navigation bars, infrastructure layout, faculty profiles, and media gallery.
  2. Build an interactive E-Book interface where chapter names are listed on the left panel, and clicking any chapter dynamically displays its corresponding text content on the right panel.
* **Coverage Note:** `[Covers: 25SACS070P Exp 25, 26 | 25BCC100P Exp 22, 23]`

---

### **Experiment 12: PHP Server-Side Fundamentals, Form Data Processing via GET and POST**
* **Objective:** Understand server-side script execution, HTML-PHP integration, and HTTP request processing.
* **Tasks:**
  1. Write basic PHP scripts embedded within HTML documents to render dynamic content.
  2. Create HTML submission forms and build PHP scripts to process submitted data using both `GET` (`$_GET`) and `POST` (`$_POST`) HTTP request methods, comparing security and URL behavior.
* **Coverage Note:** `[Covers: 25SACS070P Exp 29, 30 | 25BCC100P Exp 26, 27]`

---

### **Experiment 13: Database-Driven Web Applications & Secure User Login Authentication in PHP/MySQL**
* **Objective:** Connect PHP applications to backend MySQL databases for data persistence and user authentication.
* **Tasks:**
  1. Build a database-driven web application in PHP that connects to MySQL, executes SQL queries (`SELECT`, `INSERT`), and dynamically populates HTML tables with database records.
  2. Create a User Login and Registration form system in HTML/PHP, connecting it to a MySQL database to authenticate user credentials and maintain dynamic session workflows.
* **Coverage Note:** `[Covers: 25SACS070P Exp 27, 28 | 25BCC100P Exp 24, 25]`
