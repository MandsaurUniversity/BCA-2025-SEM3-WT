# Combined Theory Curriculum: Web Technology & Cloud Computing Applications – I

## Course Overview

* **Course Code:** 25SACS070T / 25BCC100T (Combined Stream Syllabus)
* **Course Title:** Web Technology & Cloud Computing Applications – I
* **Target Program & Semester:** BCA (System Administration & Cyber Security) & BCA (Cloud Computing) — Semester-III
* **Academic Year / Assessment Year:** 2026-2027
* **Teaching Scheme:** L-3 T-1 P-0 C-4
* **Total Duration:** 60 Theory Hours (30 Continuous 2-Hour Class Sessions)
* **Target Audience:** Merged BCA 3rd Semester Class (SACS & BCC Streams)

---

## Course Description

This combined theory course provides a comprehensive foundation in web technologies and internet applications for students of both System Administration & Cyber Security and Cloud Computing streams. The curriculum covers fundamental networking concepts and web protocols (HTTP/HTTPS, TCP/IP, Proxies, Firewalls), structured web markup using HTML/HTML5, dynamic styling using Cascading Style Sheets (CSS), client-side interactive programming with JavaScript, and server-side application development with PHP and database connectivity.

---

## Course Objectives

* To understand basic and advanced concepts of Internet technologies, web architecture, and application-layer protocols.
* To learn and apply basic and advanced tags of HTML and HTML5 to design structured web pages.
* To master CSS styling concepts, including selectors, properties, color models, layout techniques, and external stylesheets.
* To acquire client-side scripting skills in JavaScript for building dynamic, interactive, and validated web user interfaces.
* To master server-side web scripting using PHP, including form data handling (GET/POST) and backend database interactions.

---

## Course Outcomes (COs)

Upon successful completion of this course, students will be able to:

1. **CO1:** Explain the historical evolution, architectural models, networking protocols (TCP/IP, HTTP/HTTPS), proxy servers, and firewalls governing the World Wide Web.
2. **CO2:** Apply HTML/HTML5 markup elements, structure tags, forms, tables, lists, and multimedia components to build static web pages.
3. **CO3:** Analyze and implement Cascading Style Sheets (CSS) to design aesthetically pleasing, responsive, and well-structured web layouts.
4. **CO4:** Evaluate and implement client-side JavaScript logic, including control structures, functions, popup boxes, dynamic DOM manipulation, and input validations.
5. **CO5:** Develop server-side PHP scripts to process HTML form submissions via GET/POST methods and execute database interactions for dynamic web applications.

## Detailed Curriculum Structure

### Unit-I: Exploring History, Internet Concepts, Architecture & Protocols (12 Hours / 6 Classes)

**Topics:**
* **Introduction to Internet Technology:** History of the Internet, internetworking concepts, Internet architecture, and protocols: TCP/IP suite and other primary networking protocols, IP addressing and domain name system (DNS).
* **World Wide Web (WWW):** Web Clients, Web Servers, HyperText Transfer Protocol (HTTP), key features of HTTP protocol, HTTP request-response model, HyperText Transfer Protocol Secure (HTTPS).
* **Web Security & Infrastructure:** Proxy servers, Firewalls, basic security mechanisms in web communication.

---

### Unit-II: Static Web Page Development with HTML & HTML5 (12 Hours / 6 Classes)

**Topics:**
* **Static Web Page Development:** Introduction to HyperText Markup Language (HTML), Elements and Attributes of HTML, basic structure of an HTML document, Head & Body Sections.
* **Content Formatting & Navigation:** Inserting text, text alignment, using images in web pages (`<img>`), hyperlink text (`<a>`), changing font colors, Marquee tag (`<marquee>`).
* **Lists & Tables:** Creating lists: Ordered List tags (`<ol>`), Unordered List tags (`<ul>`). Creating and using tables in HTML (`<table>`, `<tr>`, `<td>`, `<th>`), table layouts.
* **Forms & Styling Controls:** Forms in HTML (`<form>`), form elements, page backgrounds, and color controls.

---

### Unit-III: Dynamic Web Page Styling with CSS & Layout Design (12 Hours / 6 Classes)

**Topics:**
* **Cascading Style Sheets (CSS):** Introduction to CSS, syntax, features of style sheets, CSS properties and declarations, CSS unit types.
* **Defining Styles & Placement:** Defining style with HTML tags, style placement: Inline styles, Internal styles, External style sheets (`.css`).
* **Styling Properties & Elements:** CSS Styling (Backgrounds, Text formatting, controlling font styles), working with lists and tables styling.
* **Layouts & Block Elements:** Working with block elements and objects, CSS Class and ID selectors, CSS Color models, grouping elements using `<span>` and `<div>` tags, header styles.

---

### Unit-IV: Client-Side Scripting with JavaScript: Functions, Variables & Logic (12 Hours / 6 Classes)

**Topics:**
* **JavaScript Overview:** JavaScript and the WWW, `<script>` element placement and syntax.
* **Dialog Boxes & Interaction:** Alert box (`alert()`), Prompt box (`prompt()`), Confirm box (`confirm()`).
* **Variables & Data Types:** Variables overview, declaring variables (`var`, `let`, `const`), types of variables, casting variables.
* **Functions & Comments:** JavaScript comments (single-line & multi-line), introduction to functions, defining and calling functions.
* **Expressions & Operators:** Arithmetic operators, assignment operators, logical operators, comparison operators, expressions and operator precedence.
* **Control Statements:** Conditional statements: `if`, `if...else`, `else if`. Loop statements: `for` loop, `while` loop, loop control (`break` / `continue`).

---

### Unit-V: Server-Side Scripting & PHP Essentials: Basics, Forms & Databases (12 Hours / 6 Classes)

**Topics:**
* **Introduction to PHP:** Overview of PHP, PHP syntax, embedding PHP in HTML, PHP data types, variables, constants, variable scope, operators.
* **Control Flow & Loops:** Conditional statements: `if`, `else if`, `switch` statements. Loops: `while`, `do...while`, `for`, `foreach`. Breaking out of loops: `break`, `continue`, `exit`.
* **Form Processing:** Working with Forms: GET and POST submission methods, processing user input, combining HTML and PHP code seamlessly.
* **Database Integration:** Introduction to backend databases (MySQL), connecting user forms to databases using PHP, executing SQL queries for data storage and retrieval.
