## 🎯 Unit Structure & Overview

The theory curriculum is structured into 5 core units:

* **[Unit I: Exploring History, Internet Concepts, Architecture & Protocols](Unit-1_Internet-Technology/) (Classes 01–06):** Covers the evolution of ARPANET, 7-Layer OSI vs 4-Layer TCP/IP models, Packet Switching, IPv4 vs IPv6, DNS resolution, HTTP/HTTPS handshake cryptography, Forward/Reverse Proxies, and Web Application Firewalls (WAF).
* **[Unit II: Static Web Page Development with HTML & HTML5](Unit-2_Static-Web-HTML/) (Classes 07–12):** Covers HTML5 boilerplate architecture, semantic text formatting, headings, image formats (JPEG, PNG, WebP, SVG), hyperlinks, relative vs absolute paths, list types, table grid spanning (`colspan`/`rowspan`), and interactive HTML forms.
* **[Unit III: Dynamic Web Page Styling with CSS & Layout Design](Unit-3_Dynamic-Web-CSS/) (Classes 13–18):** Covers CSS syntax, placement methods (Inline, Internal, External), background sizing (`cover`/`contain`), Google Fonts typography, Class vs ID selectors, Specificity weight calculations, Block vs Inline rendering (`<div>` vs `<span>`), and the 4-layer CSS Box Model.
* **[Unit IV: Client-Side Scripting with JavaScript: Functions, Variables & Logic](Unit-4_JavaScript-Scripting/) (Classes 19–24):** Covers client-side JS engine execution (`V8`), `<script>` placement (`defer`/`async`), modal dialogs (`alert`, `prompt`, `confirm`), variables (`var`, `let`, `const`), memory Stack vs Heap, strict equality (`===`), Arrow functions (`=>`), closures, and control loops.
* **[Unit V: Server-Side Scripting & PHP Essentials: Basics, Forms & Databases](Unit-5_PHP-Essentials/) (Classes 25–30):** Covers client vs server execution, PHP syntax (`<?php ?>`), variable interpolation, string concatenation (`.`), `foreach` array loops, superglobals (`$_GET`, `$_POST`), XSS sanitization (`htmlspecialchars()`), self-processing sticky forms, and MySQL database authentication via prepared statements.

## 💡 How to Use These Self-Study Lecture Guides

1. **Pre-Class Preparation:** Read the **Key Jargon & Beginner Vocabulary Dictionary** at the top of each class guide before attending lectures or starting practicals.
2. **Visual Conceptualization:** Study the **Mermaid Architectural Diagrams** to visualize server-client flow, memory allocation, and DOM hierarchies.
3. **Analogy-Driven Learning:** Refer to real-world analogies (e.g., house skeleton for HTML, picture frame for CSS background cover, smoothie blender for functions, restaurant kitchen for PHP) to grasp abstract concepts easily.
4. **Code Execution:** Copy and test the **Practical Code Examples** in your local VS Code environment or browser developer console.
